# 🛒 SauceDemo 

## 📌 Sobre o projeto

Projeto de testes manuais realizado na aplicação web Sauce Demo, com o objetivo de aplicar e demonstrar conhecimentos e práticas de Quality Assurance.

## 🎯 Objetivo

Validar as principais funcionalidades da aplicação, verificando seu comportamento esperado e identificando possíveis defeitos.

## 🔍 Escopo

- Registro de usuário
- Login
- Listagem de produtos
- Detalhes dos produtos
- Carrinho de compras
- Processo de Checkout
- Logout

## 🧪 Tipos de teste

- Testes Funcionais
- Testes Positivos
- Testes Negativos
- Testes exploratórios
- Testes de limite (Edge) (Onde aplicável)
